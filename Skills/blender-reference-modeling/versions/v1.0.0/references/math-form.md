# 数形结合：把"势"算出来，再用眼睛修到有性格

数形结合不是"用公式代替建模"。它的意思是：用少量**可控的数学对象**（曲线、曲面、距离场、噪声）去**拟合**参考图的气韵，算完要看，看完再调，形成闭环。数学服务于造型语言（节奏、对比、收头、层次、随机），不是反过来。

拟合不是终点。**拟合给骨架**（转折在哪、转多少），**审美定软硬**（顺滑到什么程度、哪处瑕疵不要）。拟合完一定要顺一遍，再放回参考视角核对（3.5、3.6 节）。拟合之前还有一步：**认线**——先确认要拟合的那条可见边，确实是模型里你以为的那条曲线（3.1 第 3 步）。

本文件管**曲线**（有性格的线）。相机与族参数的拟合见 `fitting.md`；截面、放样、叠层等构造几何见 `geometry-math.md`。

本文件是方法，不是公式全集。遇到这里没列的特征，按第 6 节的思路选对象，查资料补全（见 `research.md`）。

代码：`scripts/formkit.py`（曲线、拟合、残差、稳健损失、扫掠、距离场、随机）和 `scripts/ref_trace.py`（从参考取特征线、去拍摄位姿、透视矫正、截图配准）。两者都是普通 Python，`--selftest` / `selftest` 逐项打印误差数字。

## 1. 闭环 [已验证]

```
看  → 用一句话说出这个形的"性格"（宽而低垂？起势晚、甩得急？等厚还是渐细？）
名  → 把性格翻成可量的特征（曲率怎么变、厚度是否恒定、哪里连续、哪里转折）
选  → 选一个能表达这些特征、参数又少的数学对象（第 2 节）
参  → 参数化：3–6 个参数，每个都有直观含义（起势早晚、翘多急、甩多远）
认  → 认线：这条可见边 = 模型的哪条曲线，在参考视角下会怎么变形（第 3.1 节第 3 步）
拟  → 自己从参考图取轮廓拟合参数（第 3.1 节，主）；用户画线只用来修正意图（第 3.2 节，辅）；都要给误差数字
顺  → 骨架不动，按审美顺滑（第 3.5 节）：σ 下限由构造定、上限由性格定，报误差代价、最小半径、曲率图
回代 → 放回参考视角，比同一条线（第 3.6 节）；对不上就回到"认"或"选"，自己跑几轮到收敛
写  → 参数取整写进 spec，并按取整值复算误差；生成脚本只调函数；同机位渲染，数字过了，眼睛还要过
```

两条底线：
- **参数必须可读**：拿掉参数名后，说不出"调大它会怎样"的参数，就是错的参数化。
- **数字和眼睛都要过**：RMS 很小但不好看，说明选错了数学对象，而不是拟合没收敛。

## 2. 特征 → 数学对象（本项目已用）

| 形的特征 | 数学对象 | 为什么选它 | 本项目用处 | 状态 |
|---|---|---|---|---|
| 有节奏的曲线：缓 → 起势 → 回收 → 收头 | **曲率沿弧长分段** κ(s)，积分出曲线：θ = θ0 + ∫κ ds，x = ∫cos θ ds，z = ∫sin θ ds。κ 线性变 = 欧拉螺线（过渡顺）；κ 几何变 = 对数螺线（卷尾越卷越紧） | `z = a·|x|^p` 这类幂函数的曲率单调到底，只会"越来越翘"，没有节奏 | 檐下皮"展翼"线、翼角 | [已验证] |
| 设计尺寸（面宽、翼展）要精确落点 | 弧长参数化的曲线 + **二分 / 打靶**解首段长度，使终点落在目标 x | 曲率参数控制形，几何约束交给求解器，两者不打架 | `solve_flat_length` | [已验证] |
| "拐一下就笔直甩出去" | 曲率段后接 κ = 0 的直段（显式 `straight` 参数） | 让拟合器把曲率推到 1e-21 来"模拟"直段，数值不稳 | 檐线刀锋段 | [已验证] |
| 等厚的带（桥梁、戗脊） | 中轴用三次贝塞尔，两缘沿法线 ± w/2 偏移 | 厚度恒定是用户的明确要求；渐细笔形拟合不上（RMS 235 → 43 mm） | 戗脊 | [已验证] |
| 渐细的笔触（卷尾、枝干、刀锋翼角） | 中轴 + 宽度 w0 → w1 的幂次插值 | 一个函数覆盖一类构件 | `tapered_stroke` | [已验证] |
| 连成一片的波形面 | 沟用 cos²（单元两端值和斜率都为 0 → 相邻单元 C1 相接）；垄用扁超椭圆；两者用 **smoothmax**（log-sum-exp）过渡，k ≈ 圆角半径 | 不用布尔、不留折痕，圆角大小只由一个参数控制 | 波形瓦截面 | [已验证] |
| 搭接、压边 | smoothstep 过渡的局部抬升 | C1 连续、局部影响 | 瓦片侧搭 | [已验证] |
| 古建"分瓣"折面感 | 在四分之一椭圆上等角取点，连成 n 段折线 | 法式本身就是分瓣，不是光滑曲线 | 栱头卷杀 | [已验证] |
| 内凹的收进 | 线性收 + 抛物线 4·lu·t(1−t) | 两个参数：总收进、凹深 | 斗欹 | [已验证] |
| 柱身收分 | 高度比的线性函数（宋制约 1%） | 古建有定制，查到就用 | 收分 | [已验证] |
| 不规整、但可复现 | 受控随机：种子 + 件名哈希 → 随机源；fbm 多尺度；振幅写进 spec；均值为 0；接触面不动 | 见第 5 节 | 瓦片、石块、崩口 | [已验证] |
| 成因分布（雨痕、返潮、苔） | 法线、高度、射线遮挡的组合场 | 见 `gn-patterns.md` | 表面处理 | [已验证] |
| 轮廓由几个构件的外缘拼成 | 分段 κ(s)，交接处插一段小圆角（半径 r、转角 Δθ）；每段常曲率或线性曲率 | 光滑曲率族遇到拐角只能来回振荡；拐点的位置、转角本身就是可读的设计量 | 拟合方法实测过（3.4）；当时那条线认错了，还没有正确用例 | [实测] |

对应代码（`formkit.py`）：曲率分段 `kappa_curve`；终点落点 `wing_curve`（平段长度解析求）；等厚带 `offset_curve`；渐细笔触 `tapered_stroke`；smoothmax / smoothstep 同名；拐点段 `fillet_seg`；受控随机 `rng` / `noise1` / `fbm1`。

## 3. 反推参数：自己拟合为主，用户画线为辅

**主次**：
- agent 自己从参考图取轮廓、拟合参数，是主路径。用户不画线，流程也必须走得通。
- 用户画线是**修正信号**：告诉你哪里没抓住"意图"。它不是拟合的主要数据来源。
- 两者冲突时：比例、尺寸听参考图；"势"和性格（这一笔要不要甩、要不要等厚）听用户。冲突本身要报告出来，但先排除"自己读错了线"（3.1 第 3 步）。

### 3.1 自拟合：从参考图到参数（主路径）

1. **清点参考**：按第 1 步"读图分类"剔除插图、标注、干扰物；判断投影方式（正视 / 略仰 / 强透视）。强透视先做矫正（四角点单应），或只取比例、不取绝对形。[已验证：剔除插图后宽高比从 0.875 改为约 1.1]
2. **定大形数字**：剪影外框、宽高比、竖向分段占比、柱距 / 檐宽等关键比例。用工具出数字（扫线找边、外框），不靠目测。这些数字直接定 spec 的大形参数。[已验证：本项目先手工粗量，误差约 ±5–10%；之后应当用 `img_probe` / `img_measure` 复核]
3. **取特征线**：`ref_trace.py trace` 在 ROI 内逐列取边，得到**密集**有序点列（亚像素，合成图自检 RMS 0.13 px）。按第 1 步分清是哪条边；被斗拱、匾额挡住的中段用 x 范围排除；窄的挂件由滑动中位数剔除并报告个数。叠图（`--overlay`）看一眼再用。[实测：ref02 两侧各约 130 点]
   - 不要手取十几个点：同一个对象族，手取 14 点和密集取点拟合，误差差 4 倍（数字见 `case-xiuxian.md`）。数据本身就是精度上限。
   - **先认线，再取线** [实测]：写一句"这条可见边 = 模型里的哪条曲线，在参考视角下会被透视变成什么样"，再取。
     - 透视里露出来的底面、侧面的边不是立面线。例：仰视的屋檐下面那片深色是檐底，深色带的**下边**是檐底后沿和侧檐的透视轮廓，在翼尖向檐口收拢，看起来像"急拐 + 上挑"；前檐口的立面线是深色带的**上边**（瓦头结束处），它横贯全宽、左右逐点一致。
     - 反例：xiuxian 项目曾把下边当檐下皮拟合，误差只有 23 mm，建出来屋檐整体上卷，用户一眼看出"这是另一种风格"（数字见 `case-xiuxian.md`）。
     - 两个信号提示可能认错了线：这条线在中段被遮挡、只剩两翼（真正的檐口线应当贯通）；拟合结果和用户意图明显对不上。
     - 两个区域之间的分界线（如瓦面 / 檐底）不是剪影，逐列找"第一段前景"取不到。用连续路径法：逐列算边缘强度，在相邻列位移受限的条件下取总强度最大的一条（`skimage.graph.route_through_array`、OpenCV `IntelligentScissorsMB` 都是现成实现）。
4. **去拍摄位姿**（对称物体）：`ref_trace.py sympose` 只用"左右镜像最吻合"估中轴偏移、倾角、水平透视，不需要形体模型。去掉的这部分是拍摄造成的，不该让形体参数去吸收。[实测：ref02 左右不对称 4.33 → 1.70 px，倾角 −0.52°，中轴偏 7 px]
5. **标定**：用一个可信的已知尺寸（或大形比例）把像素换成 mm；多视图时检查各视图尺度是否一致。
6. **拟合**：与 3.3 相同（损失按 mm、多起点、物理下限、取整复算）。选对象族看 3.4。
7. **自己多轮，再交结果**：拟合 → 顺滑 → 构造检查 → 参考视角回代比对，结果再回到拟合，几轮后收敛。这个循环由 agent 自己跑，交给用户的是收敛结果和每轮记录。
   - 要出档，就出同一来源的审美档（软硬、收放），例如 xiuxian 项目的概念立面 A / B / C。
   - 不要把"用户画线来的"和"参考拟合来的"并排当方案：用户看到的是两种风格，不是同一个形的打磨。用户的线只用来修正。[实测，2026-11-20 用户纠正]

### 3.2 用户画线：修正意图（辅路径）[已验证]

用户在渲染图上画线，说明你的拟合在某处没抓住意图。这时：

1. **配准**：把画线截图对齐到渲染画布（模板匹配：缩放 × 平移搜索，误差取非标注像素的灰度差）。配准常量写进 spec。
2. **取点、分笔**：取出标注像素，逐列取连续段，按位置分成不同笔画（上缘 / 下缘 / 端头），剔除不属于目标的部分（如底座侧边）。
3. **用原参数算一次误差**：先看现有参数离画线多远（本项目 76 mm / 235 mm），判断是参数没调好，还是**数学对象选错**。渐细笔形怎么调也贴不上等厚带，就该换对象（第 2 节），不是硬拟。
4. **拟合**（同 3.3）。
5. **读意图**：做一个"约束版"（如强制收笔角 = 檐尖切角）对比"自由版"。约束版误差明显更大（实测 104 mm 对 43 mm），说明用户那一笔是有意的，保留自由版。
6. **回写**：画线修正的是参数和对象，不是在某一处单独打补丁。修完后用 3.1 的大形数字再核一遍，确认没有把别处带偏。

### 3.3 拟合本身（两条路径共用）[已验证]

- **损失**：点到曲线的几何距离（`dist_to_polyline`，不是竖直差），单位 mm，取 RMS。参考上有挂件、遮挡残留时用 Huber（`huber`，δ ≈ 1.5 倍取点噪声），报告时仍给 RMS。[Huber 自检：10% 遮挡块下 L2 偏 7.9、Huber 偏 0.33]
- **优化**：Nelder–Mead，多起点（`fit_multistart`，不需要 scipy）；装了 scipy 时也可用 `scipy.optimize.least_squares`（自带 Huber / soft_l1 损失和边界）。给参数加**物理下限**，防止退化（如曲率回落比例 ≥ 0.02）。
- **撞边界要读**：`at_bound` 非空说明对象族想要的形状它给不了。ref02 上 `wing_curve` 的回落比例撞下限，意思是"想要更急的拐"——后来证实那里是拐角（3.4）。
- **复算**：把参数取整成要写进 spec 的值，**用取整值重算 RMS**，并直接打印 spec 片段，杜绝抄写误差。
- **报告**：改前、改后的 RMS；叠图（参考轮廓或用户画线叠在渲染上）。

### 3.4 更准、更细从哪里来：选对象族，不是加参数 [实测]

按这个顺序找，每一步都有对应的检查。复现示例：`python scripts/examples/ref02_refit.py`（数字见 `case-xiuxian.md`；注意那个示例拟合的线后来证明认错了，但这里的方法不受影响）。

1. **数据**：密集取点，不手取十几个点。数据本身就是精度上限。
2. **位姿**：对称物体先去拍摄位姿（`sympose`），别让形体参数替位姿背锅。
3. **下限**：左右不对称、单侧自由拟合的误差就是取点噪声的下限。拟合到下限附近就停，再往下是过拟合。
4. **有符号残差**（`signed_dist`，对称物体两半叠在一起看）：
   - 两侧**同形** → 有形体特征没进模型；
   - 两侧**反形** → 位姿或真不对称；
   - 像白噪声 → 到底了。
5. **换对象族**：残差大的地方放大看。是拐角就用 `fillet_seg`（小圆角）接两段，不要给光滑族加节点去追：只会振荡（曲率图上 κ 来回变号）。
   - 拐点位置、转角是能读的设计量，换种子重拟也稳。
   - **数据定不了的参数**（如 1 px = 20 mm 的图上的小圆角半径）：两次拟合差一个数量级、误差却一样。不要报成拟合值，交给审美 / 规制定，并注明来源。
6. **挂件、瓦口锯齿**不进主曲线：它们是另外的构件，单独建；拟合用 Huber 让它们不拉偏主曲线。

一句话：**轮廓常是几个构件外缘的并集**，"更细"是把它拆回构件，各自用简单对象。但拆之前先认线：透视轮廓看起来也像"几段拼起来的"。

### 3.5 拟合之后要顺：骨架听数据，软硬听眼睛 [实测]

拟合会把两类东西一起搬进模型：
- 数据定得住的骨架：转折的位置、转角；
- 数据定不了、或不该要的：拐角圆角半径、画面笔触、构件交接处的小台阶。

后一类交给**顺滑**，由审美定，不交给拟合器。

**做法**：`formkit.fair_kappa(segs, σ)` 把 κ(s) 沿弧长做高斯摊开。
- 每处转折的转角只摊开、不增减：末端切角不变；落点不变，余量记到平段上。（通用平滑样条做不到这一点，会改掉末端切角。）
- 拐角变成曲率连续的缓弯。单个转角 Δθ 摊开后，最小半径 ≈ σ·√(2π)/Δθ。
- σ 是可读参数："转折的软硬"。

**σ 的范围，两头由数定，中间由眼睛定**：
1. **下限来自构造，而且要用最严的那道查**：
   - 第一关（2D）：等厚带沿法线偏移，拐角半径小于带厚就自交。
   - 第二关（3D 派生构件）：这条线还驱动平面收分、椽子排布等。立面过关不等于派生构件过关（实例：椽尾平面扇往回折、尾部交叉，审计报一串亚毫米碎面）。
   - 做法：把下游构件的排布函数**纯计算**跑一遍扫 σ（不建模、几秒钟），查单调性 / 交叉 / 最短间距；不要等建出来让审计报碎面。
   - 软硬固定后要重拟其余量，重拟会挪动别的参数，可行性对 σ（或平面收拢长这类软硬量）**不单调**。所以每个候选都走"重拟 → 取整 → 构造复查"，在通过者里取误差最小的；骨架上扫出来的下限只是起点 [实测]。
2. **上限来自性格**：σ 大到把几处转折摊成一段均匀圆弧（曲率图变平）时，拐角没了，性格也没了。
3. **中间**：agent 先按"数据还容得下的最顺一档"自己定（σ 往上加，误差开始明显变大的拐点）；需要人挑时，出同一来源的 2–3 档，附误差代价、最小半径、曲率图、同机位图。由人挑，不由 RMS 挑。

顺滑不是抹平性格：合适的 σ 下，曲率图会从"尖峰 + 突跳"变成"起势 → 回收 → 收头"，节奏反而显出来。对用户画线的拟合也要顺（实例：曲率段直接接直段处 κ 突跳，顺滑后误差只多 1 mm，曲率处处连续）。

### 3.6 回代：放回参考视角，比同一条线 [实测]

拟合误差小只说明"贴住了取到的点"，不说明取对了线。收敛前必须回代一次：
1. **对相机**：用自己的模型去对参考的视角，只调两三个量（仰角、相机高度，必要时视场角）。参考接近正视时，正交相机就够。
2. **渲染并取同一条线**：在渲染图上用和参考相同的方法取线，两边一起叠图、算误差。
3. **多条线一起对**：参考上能对应的线（如檐口线和檐底下沿）都要对上。只对上拟合的那一条、另一条差很多，说明认错了线或相机不对，回到"认线"。
   - 辅助线也要认 [实测]：先量它和主线的关系（逐段间距、在哪里交汇），再写它的代理。间距恒定 / 突然塌落 / 恒等于某个构件厚度，各自对应一种结构。
   - 辅助线的代理按**构建规则**取"最低（最外）可见边"：几个候选构件投影后取包络，构件在哪里有、哪里没有照构建脚本的判据，不要假设处处都有。
   - 辅助线主要定相机和它自己牵涉的结构量（如平面收分），不让它去拧主线的形。联合拟合时形参和相机一起撞边界、主线误差反而变差，就是辅助线代理认错了。
   - 数据定不了的量（相机距离、急收的长度）换起点会漂，不报成拟合值：相机不进 spec，结构量交给构造或审美。
4. **渲染取线用分类掩膜** [实测]：Workbench 平涂、按材质上色（如 屋面 / 深色带 / 其余）、关抗锯齿、透明背景。取线不受灯光影响，规则和在参考上取线一致；同时报渲染左右差（应 < 0.5 px）和渲染对代理的差（验证代理）。
5. **记录每一轮**：误差、σ、曲率图、叠图，失败轮也记。交给用户的是收敛结果和这份记录。

相机只用自己的模型去对，不引入单图标定 / 深度估计模型。参考是画时这类模型不可靠；参考是真实透视照片时可用的工具见 `toolchain.md` 末节。

### 3.7 拓扑歧义与方案族 [实测]

单张参考只约束投影。深度方向的结构（转角是刀锋还是真转角、山面有没有、檐底是平是折）常常在参考视角下投影几乎一样：
修仙牌楼 ref02 仰拍里，真转角的山面檐只要抬平，前檐、戗脊沿视线对位后和刀锋翼在照片上只差约 9 px（后檐 / 后角落到下轮廓以下），而俯视、3/4 下是两种屋顶。

1. **先判断是不是歧义**：把各候选的同一条线沿视线对位到同一像点（`camkit.Pinhole.slide` / `slide_to_plane`；像点不变 = 在这张参考上按新平面重拟合），再比剩下的残差。剩下的差 ≤ 几倍噪声底、却在别的视角下天差地别，就是歧义。
2. **做成方案族**：离散结构 = 族（`roofkit` 的 blade / true）；族内用一个开关或一个连续参数（axis_beam、sag 0 → 1）。连续参数让人不必二选一：中间档常常两头兼顾。
3. **公平**：每档同样对位、同样的从属规则（如角梁尾的取法）、同一个取线函数；不公平的对比先修再比（C1 吃过两次亏：没对位、山面镜像下垂 1.75 m 被算成"真转角的代价"）。
4. **同视角并排**：参考机位叠图 + 正立面 + 平面 + 3/4 仰 / 俯（`preview.zrender` + `variants.sheet`），表里列残差、构造检查、关键尺寸（如山面下垂、排水抬高）。
5. **由人定、写下来**：结构由人按造型定；决定和理由写进 spec（首选 / 备选 / 默认），注明"这里以造型为准，参考残差只作约束"。

## 4. 连续与连接 [已验证]

- 用户说"能连上的地方最好连上"：拼接处是最先暴露"计算机感"的地方。几条线能合成一条连续轮廓的，就合成一条（正脊 + 两条戗脊 → 一条脊带）。
- 选连续阶：结构转折处 C0（故意的棱）；同一构件的曲线内部至少 C1；视觉上要"一气呵成"的长线 G2（曲率连续）——κ(s) 分段且相邻段在接点处 κ 取值相同，才满足。注意：曲率段直接接 κ = 0 的直段时，接点只有 G1（本项目的刀锋段就是有意如此）。
- 反过来，**不同构件的交接处本来就是拐角**（如正脊与脊头、台明与踏跺）。在那里强求 G2，会把拐角抹成大缓弯，形就软了。先判断这条轮廓是一个构件还是几个构件拼的（3.4），也先确认它不是透视轮廓（3.1 第 3 步）。
- 圆角用 smoothmax / smoothstep 这样的解析式，不用布尔加倒角。

## 5. 受控随机的四条约束 [已验证]

| 约束 | 做法 |
|---|---|
| 可复现 | 随机源 = 哈希（全局种子 + 件名），重建结果完全一样 |
| 有边界 | 每种随机的振幅写进 spec（如瓦径 ±3%、方向 ±1°） |
| 多尺度 | 低频（米级起伏）→ 中频（构件级）→ 高频交给材质 Bump |
| 守结构 | 接触面、对位点不动；对称轴附近衰减；均值为 0 |

## 6. 遇到新特征：怎么选数学对象（发散）

先回答四个问题，再去找（或查）对象：

1. **它是线、面、体，还是分布？**
   - 线：曲率族、样条。
   - 面：扫掠、放样、隐式面。
   - 体：距离场、体素。
   - 分布：点过程、规则生长。
2. **它的"性格"在哪个量上？** 曲率变化？宽度变化？疏密？朝向？选能**直接控制这个量**的对象。
3. **它有法式 / 规制吗？** 古建有材分、斗口模数，机械有标准件，生物有生长规律。有规制先查规制（`research.md`），规制给比例，数学给形。
4. **它要和谁连续？** 决定端点条件（位置、切向、曲率）。

候选对象（下列本项目未用到。[自检] = `formkit.py` 里有实现、合成数据自检通过，但还没在完整项目里用过；用到时写小样验证，再升级标记）：

| 特征 | 候选 | 状态 |
|---|---|---|
| 浮雕、透雕（照轮廓，不照明暗） | 描轮廓 → 有符号距离场 d（`polygon_sdf`）→ 高度 h = H·f(d/w)，f 用"斜切边 + 微鼓面"剖面（`relief_height`）；多层轮廓叠层次 | 距离场与剖面 [自检]；整件浮雕 [待验证] |
| 虬曲的树、枝、藤 | 中轴曲线（κ(s) + 低频噪声 `fbm1`）+ 变截面扫掠（`sweep`，标架用 `rmf_frames` 防翻转）；分叉用带种子的规则（L-system、空间殖民算法）；同一生成器换种子与包络出多件 | 扫掠 [自检]；分叉规则 [待验证]，查资料 |
| 程式化的云纹、卷草 | 对数螺线族（`kappa_curve` 的 "exp" 段）+ 渐细笔触；多条共享一个包络 | 曲线 [自检]；整体构图 [待验证] |
| 疏密有致的散布 | 泊松盘采样（`poisson_disk`，最小间距）+ 密度场 | 采样 [自检]；密度场 [待验证] |
| 比例体系 | 模数制（如斗口、材分°）：所有尺寸 = 模数 × 份数 | [待验证]，查规制 |
| 自由曲面拟合照片轮廓 | 多视轮廓 → 截面 → 放样（`loft`）；或可微渲染反推 | 放样 [自检]；多视反推 [待验证] |

**发散的边界**：选对象时优先"参数少、含义直观、能连续"的；不要为了显得数学而用复杂对象。一个对象能服务多处（如 κ(s) 同时管檐线、翼角、雀替底边、卷尾），是好对象的标志。

## 7. 判据：数学层面的检查

（RMS、IoU 已在本项目用过；曲率图、残差图在 ref02 重拟合里用过 [实测]；敏感度扫描是建议做法 [待验证]。）

- **曲率图**（`discrete_curvature`）：画 κ(s)。单调到底 = 呆板；有平段、升段、回落、收头 = 有节奏；**正负来回变号 = 在振荡**，对象族不对（3.4）。
- **残差图**（`signed_dist`）：对称物体两半叠在一起看，同形 = 漏了形体特征，反形 = 位姿 / 不对称，白噪声 = 到底了。
- **误差**：RMS（mm）对参考 / 画线，同时报下限（左右不对称、单侧自由拟合）；剪影 IoU（`scripts/silhouette_iou.py`）。
- **参数敏感度**：每个参数 ±10%，渲染一排变体给用户挑。这同时也检验参数是否"可读"。
- **退化**：参数撞到下限或上限、曲率趋于 0 或无穷大、偏移曲线自交——都说明对象选得不合适。
