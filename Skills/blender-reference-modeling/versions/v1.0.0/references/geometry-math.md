# 硬表面与装配的几何原理

曲线的性格在 `math-form.md`，相机与族参数在 `fitting.md`。本文件讲"截面 → 放样 → 装配"这条构造链的数学：为什么这样做、条件是什么、在哪段代码里有实现。
具体物体的几何代码由执行模型按这些原理现写；可复用的部分已在 `scripts/`（见 `code-index.md`）。

记号：沿支承主轴的位置 v，绕轴角 θ，支承截面 S(v, θ) → (x, z)（绕一圈为凸闭曲线），倒角宽 w_b，层间净距 c。

## 1. 支承体 [实测]

- 支承 = 轴线 c(v) + 截面 S(v, θ)。截面常用椭圆 (a(v)·sin θ, b(v)·cos θ) 或超椭圆；a、b 是少参数光滑函数（`fitting.md` §5），可加扭转 φ(v)：θ → θ + φ(v)。
- 轴线是曲线时，截面沿旋转最小标架（RMF）排，防止翻转（`formkit.rmf_frames`）。
- 支承带表面起伏（绗缝、肋纹）时，件的基面取"起伏顶 + 间隙"的包络，不取名义面。
- 代码：`support.Surface(f(u, v))`（点、法向、标架、等参线、偏移壳）；`support.Support`（高度场 / 多边形汤射线）。

## 2. 折面板截面：硬表面件绕支承 [实测]

刚性件有自己的折线截面，支承只用来定位和查干涉。
- **顶点**：Pᵢ = f·S(v_ref, θᵢ)，θᵢ 是折线角（端角 + 中间折点）。
- **外扩系数 f**：要求每条弦 PᵢPᵢ₊₁ 上的点都在支承外。点 p 的"支承半径比" ρ(p) = |p| / r_S(方向 p)，条件是弦上 min ρ ≥ 1，所以 **f = 1 / min ρ**（弦上采样求，`facets.clear_scale`）。
  圆上有闭式 f = 1/cos(Δθ/2)，**扁截面上不够**（弦中点会切进去），所以一律数值求。
- **厚度**：内表面 = 顶点沿角平分线外法向移 h（离支承的抬高），外表面再移 T；平分线方向的长度要除以 cos(半夹角)（斜接补偿），否则两侧面厚度不等。T 可逐顶点不同（凸起包边 / 凹面板）。
- 结果是一个闭合环（外表面 n 点 + 内表面 n 点反序），直接拿去放样。代码：`facets.facet_ring / split`。

## 3. 放样与四边面平面性 [实测]

- **同拓扑环**：每站截面点数相同、顺序相同，相邻环连四边面；只在端面用平面 n-gon 收口。
- **平面性条件**：相邻两站对应边平行，四边形就是梯形、必共面。两种做法：
  - 同一放样件各站用**同一个 f**（`facets.loft_scale` 取各站最大）；
  - 或用**相似截面**：各站截面 = 参考站截面 × 标量 s(v)（+ 平移）。逐站缩放、外翻都可以这样做而保持共面。
  不满足时 Blender 三角化的对角线会切进支承，平着色出 X 形折痕。
- **相似放大的外翻 / 收分**：s(v) 是分段线性时，每个转折点必须是一个放样站；否则站间直线插值的 s 和真实 s 不同，上下两层用同一 s(v) 时会互穿（护臂腕甲：外翻起点没设站 → 上下层 18 面相交）。

## 4. 站点规则 [实测]

站上全净、站间穿进支承，几乎都是站点问题。
- **角范围随站变化的段要密**：截面顶点在相邻站间绕轴移动 Δφ，弦切过支承弧的深度 ≈ r·(1 − cos(Δφ/2))。要求它 < 净距 → 每段 Δφ 小 → 站加密（端切角、尖唇、斜缘）。
- **驱动量的每个转折处设站**（外翻、收分、厚度渐变、折线角插值表的节点）。
- **站距下限**：≥ 2–3·w_b，否则倒角在窄条上自交。加密站离已有关键站 < 1 mm 的丢掉（护臂肋纹壳：加密站离叠片站 0.6 mm → 倒角自交）。
- 审计报相交后，用 BVH 取相交面中心，读出 v 位置，定位到哪两站之间。

## 5. 倒角约束 [实测]

活 Bevel（限角）是硬表面棱线的命，但有几何前提：
- **面宽 ≥ 2·w_b**：收拢段（尖唇、端头）的折线不要用夹紧（clamp）把折点挤在一起，那会挤出窄条；**按角范围等比压缩**所有折点，各面均匀收拢（护臂腕甲：夹紧法在 v = 238.8 处两折点 19.8° / 21.4° → 自交；等比压缩后 0）。
- **台阶高 ≥ 2·w_b**：剖面阶梯、回转件的台肩（销帽 vs 销身）都算。销身半径 2.4、帽 2.8 时 0.25 倒角出 96 个退化面；倒角降到 0.15 后 0。
- 小件倒角按件的最小特征尺寸取，不按大件的值套。
- 原网格干净、求值后自交 / 退化 → 先查这三条，再查位移。

## 6. 叠层：谁压谁、抬多少 [实测]

- **顺序**：从被压的那件往上逐件做；每件的倾角 / 抬高按它压住的那件**实测外表面**求，不按厚度累加（两层折点不同、f 不同时弦拱失配）。
- **间距函数**：沿若干径向射线 d，gap(d) = 上层内表面交点距离 − 下层外表面交点距离；只计两层都覆盖的方向；取重叠段若干站的最小值。
- **求解**：gap 随抬高 / 倾角单调增 → 二分求最小值使 min gap ≥ c（`facets.min_gap / solve_up`）。
- **上层的每个子块都要参与**（主板 + 尾板 + 凸起），漏了一个就在那里互穿（护臂：尾板没进求解 → 与下层 29 面相交）。
- **随机实例**的净距 = 件面高 + 名义净距 + 随机量（位置 ×2、角度 × 件距、缩放 × 件高）+ 曲率失配（按每处实际矢高差）——`instancing.stack_drop`。
- 弯曲支承上的直杆叠层（椽、龙骨）：重叠段上 max(下层顶 − 上层底) + 横滚下棱 W/2·sin(横滚) + 抖动余量。

## 7. 面上安装件：块、槽、凸台、铰座 [实测]

把一个小件平放到板上，常见错误是让它"切断"板、或沉进板里、或悬在板外。做法：
1. **专设安装折面**：在截面折线里加两条折线角，使安装位置正好是一个平面（护臂：铰座折面 18°–62°）。板保持连续，不为安装件切断。
2. **局部标架**：取该折面在安装段两端两站的四个角点 A₁A₂（前站）、B₁B₂（后站）：ex = A₂ − A₁ 方向（沿板），ey = 两站中点连线方向（沿轴），ez = ex × ey 朝外。
3. **落座高度**：支承非线性时折面沿轴略弯。在占地范围内采样折面点，取 max((p − c)·ez)，件底抬到它之上 + 小间隙（0.1–0.3 mm，避免共面贴合被审计报相交）。
4. **沿轴范围**：只占外露、平的一段——让开上一层压住的后缘和本层前缘斜面，再离上一层前缘留净距（护臂 2.5 mm）。
5. **造型照局部定**：长宽比与朝向（护臂铰座：沿板方向宽、沿轴方向窄）、窗 / 槽形状（长槽而不是方窗）、内件（铰销横贯槽长、顶面约与盒顶齐）。逐件对照（SKILL §4b）核这些。
- 代码：`scripts/parts.py` 的 `face_frame`（第 2 步）、`seat_offset`（第 3 步）、`block`（开窗盒）、`lathe`（销）、`rivet`；完整用法参考 `default-workspace/case-gauntlet/gen2.py` 的 `band()`。

## 7b. 软件与小五金 [待验证：冷读审查提出，还没建过]

**软件**（皮带、衬布、垫层）：薄、跟形。
- 皮带：支承面上的一条测地线 / 等参线作中线，向外偏移皮带厚度的一半 + 净距；截面是圆角扁矩形（4–8 段）。端头收法：穿扣的一端过扣框后折回压在自身上；尾端或掖进相邻硬件下（让开它的落座面）、或露头切成圆尖。
- 衬布 / 皮板：支承面整体外偏移成薄壳（`support.Surface` 的偏移），边缘轮廓从参考剪影拟合，缝线走边缘偏移线（detail，route 通常 normal / material）。

**柔性件上的安装件**（皮带上的带扣、皮板上的铆钉）：没有可专设的平折面。
- 标架取安装点处的面帧：法向 = 柔性件面法向，ex = 中线切向；
- 件按自身刚性造型，底面只在占地中心贴合，四周允许微小悬空（≤ 柔性件厚度的一半），或把柔性件在占地范围内局部压平到件底所在平面；
- 落座高度同 §7 第 3 步（占地范围内实测最高点 + 小间隙）。

**小五金**：
- 带扣 = 框（圆角矩形管：沿闭合路径扫掠圆截面，`sweep.sweep`）+ 扣针（一端绕框横档转一圈的细杆）+ 穿过的皮带（中线从框下穿过、绕横档折回）；
- 带环（keeper）= 贴着皮带外表面的一圈扁矩形扫掠；
- 铆钉 = 回转件（§8）。
代码：`scripts/parts.py` 的 `strap`（中线 uv → 外偏、圆角扁截面、`tip` 尾端收尖）、`surface_seat`（柔性面落座）、`buckle`、`keeper`、`tube_loop`（任意闭合截面沿闭合路径）[自检]。

## 8. 小件原语 [实测]

- **开窗块**：外环 + 内环（窗口）+ 窗底，一个闭合实体，全四边面（`parts.block`）。
- **回转件**（销、铆钉、螺栓）：剖面 (r, z) 点列绕轴旋转 → 四边面环，端面 n-gon；台肩高 ≥ 2·w_b（§5）（`parts.lathe / rivet`）。
- **沿路径扫掠**（包边、线脚、管）：`sweep.sweep / stations3`；折角处剔站距离 ≥ 截面在折角内侧的伸出量。

## 9. 审计的几何含义 [已验证]

- **求值后审计**：Bevel / GN 之后的网格才是渲染的东西；原网格干净不代表求值后干净。
- **件间干涉**：BVH 两两求交；共面贴合也算相交 → 设计上贴合的件留 0.1–0.3 mm，或设计上嵌入的件（铆钉、垫片）不放进审计并写明。
- **定位**：相交 / 退化面中心坐标 → 换算到 (v, θ) → 对应到哪个站段、哪个折面，再回到 §3–§6 找原理层原因。不用 remove_doubles / 删面把问题藏起来。
