# 对位与族参数拟合：相机、单视图歧义、数形互证、支承体

曲线怎么拟合见 `math-form.md`。本文件管另外两件事：**参考视角的相机怎么定**，以及**识别给出的结构里那几个族参数怎么从参考读出来**。
核心立场：结构来自识别，优化器只调少数可读参数；几种数据互相打架时，先怀疑形，不调权重。

## 0. 坐标、单位与判据数字 [已验证]

- 定一次写进 spec：单位（mm）、场景比例（1 BU = 1 m）、前向、上轴、原点（台基中心地面 / 肘端轴心等）。每件原点在接口中心。
- 大形判据示例：段占比误差 < 5%，轮廓 RMS < 画面高 1%。
- **剪影 IoU 及格线按场景定口径**（看结果前定，写进 `accept.json` 的理由）：

  | 场景 | 粗模（检查点 A） | 细模（检查点 B） |
  |---|---|---|
  | 照片 / 手绘，单视图，两端有遮挡 | ≈ 0.8 即停 | 0.75 左右 [实测：护臂] |
  | 渲染图 / 工程图式正交视图，同机位、无遮挡 | ≈ 0.9 | ≥ 0.95 [自检：合成小柜，候选模型错 5 处仍有 0.96] |

  IoU 是外包络的量，剪影内部的件对它几乎没有贡献——过线只说明大形没错，不说明像。`silhouette_iou.py` 的 `worst_cols / worst_rows` 指出最不一致的列 / 行（细杆、出挑、腿的撇角常在这里露出来），读差异时先看它们。
- **没有现成先验的绝对尺度**（家具、器物、机械件）：找一个能查到标准的尺寸定尺度——座高、桌高、门洞、把手孔距、螺纹规格、人手宽——查一手来源（`research.md`），其余全按比例从参考读出；`measure.json` 里写单位和尺度来自哪一个量。

## 1. 针孔相机与参数化 [实测]

像点 `u = f·(r·(P−E))/(d·(P−E)) + u0`，`v = f·(u′·(P−E))/(d·(P−E)) + v0`。E = 光心，d = 视线方向，r / u′ = 像面右 / 上轴，f = 像素焦距。

- 参数化要让每个量有直观含义、彼此不冗余：**视线方向**（相对初始方向的两个小扰动 a、b）、**绕视线滚转**、**距离 D**、**像面平移 du、dv**。焦距通常已知或取常用值（如 70 mm 全画幅 → f_px = 70/36·H），不和 D 一起放开。
- 进 Blender：`lens = f_px·36/H`（`sensor_fit = VERTICAL`，传感器高 36）；像面平移 → `shift = −du/max(W, H)`。
- 代码：`scripts/camkit.py`（`Pinhole`、`look_at`、`project`、`slide`）；参考写法 `default-workspace/case-gauntlet/fit/fit_cam_sil.py`（多起点 + 剪影微调）、`render_fit.py`（拟合相机进 Blender）。

## 2. 单视图分不开的量 [实测]

- **大小 ↔ 距离**：整体放大 k 倍同时距离放大 k 倍，像不变。所以**绝对尺寸取先验固定**（人体前臂粗细、标准件尺寸、规制），只拟合比例与相机。两者一起放开，优化器会用怪视角凑点（护臂：臂径被压到 0.57 倍、视线顺着臂轴）。
- **冗余参数**：一个全局比例和各段长度的族参数重复（全局轴向缩放 ≡ 各段同乘），固定其一。
- **深度方向的结构**：投影几乎一样的几种结构，残差只能当约束，不能用来选 → 方案族（`math-form.md` 3.7）。
- **参数撞边界要读**：意思是"这个结构给不了数据要的形"——先查认错件、标错点、少了一个独立参数，不放宽边界。

## 2b. 多视图参考 [待验证：冷读审查提出，还没在完整项目上跑过]

一张参考里常有正 / 背 / 侧几个视图，或同一件转过一个角度的两张。多视图能消掉单视图的歧义，但视图之间也会互相矛盾（尤其是生成图）。

- **清点**：每个视图拆成子图（region），记朝向、大致转角、有无透视；登记到 `ident.json` 的 `views`。插图 / 放大拼图如果是同一件的局部，标 aux 只作识别证据，不进相机拟合；是别的东西就归干扰物。
- **选主视角**：剪影最完整、遮挡最少、特征最多的一个标 primary，先在它上面定相机与大形；其余标 aux。
- **联合拟合**：每个视图一台相机，物体只有一个。目标函数对各视图求和（§4 的式子每个视图一份），相机各自独立、族参数共享；单视图下分不开的"大小 ↔ 距离"在两视图下仍要取一个先验尺寸（或已知形）定尺度，各视图的尺度必须一致。
- **两视剪影定截面**：正视给宽度、侧视给深度，支承体的 a(v)、b(v) 可以分别拟合，不必用扁率先验（§5）。
- **定不定得了，看不确定度**：联合拟合后读每个族参数的 1σ（`multiview.joint_fit` 的 `std`）。某个量 1σ 和它要求的精度相当，就是这组视图定不了它——加视图、加已知形，或列入歧义。合成自测：只用俯视图时厚度 1σ ≈ 6 mm（偏了 6 mm），加侧视图后 1σ ≈ 0.3 mm。
- 代码：`scripts/multiview.py`（`View` 基准姿态 + 小扰动参数化，俯仰接近 90° 也不万向锁；`OrthoView` 正交视图，参数是像素 / mm 比而不是距离；`joint_fit`）[自检]。
- **正交多视图的捷径**：工程图式的正视 + 侧视（+ 俯视），每张图只有比例和平移两个未知，宽、高从正视读，深从侧视读，一个先验尺寸定比例即可，不用拟透视相机。
- **视图对不上时**：先查是不是认错了对应（左右手、同一件的不同状态）；确是参考自相矛盾，以 primary 为准，矛盾处列进歧义清单，不取平均。
- **能消掉的歧义不出方案族**：深度方向的结构在另一视图里看得见，就用那个视图定，不再出 2–3 个方案让用户选。

## 3. 已知形是强约束 [实测]

物体上形状已知的特征直接约束视角，比一堆散点可靠：
- **环**（绕柱 / 绕臂一圈的缝、箍、口沿）投影成椭圆：短轴 / 长轴 ≈ |cos α|，α = 视线与环所在平面法向（即轴）的夹角；用拱高 / 半弦读同一个量。护臂：肋纹环给出视线与臂轴约 60°，作为视角先验项。
- **直线族**：平行线的灭点给方向；对称轴给滚转。
- 这类先验以软约束进入目标函数（§4），权重按读数误差定。

## 4. 目标函数与数形互证 [实测]

```
L(c) = λ·(1 − IoU(剪影_模型(c), 剪影_参考))  +  Σ_i ‖x_i(c) − x̂_i‖² / σ_i²  +  Σ_k (先验_k 残差)² / τ_k²
```
- **剪影项**管整体包络；**特征点项**（铰座角、板尖、端点）管内部结构的位置；**先验项**管视角等已知量。σ 是标点误差（几像素），不是调参旋钮。
- 剪影是不可导的像素量：先用特征点 + 先验多起点 `least_squares` 得初值，再在初值附近用无导数法（Powell / Nelder–Mead）加剪影项微调。
- **数形互证（判形不判相机）**：分别以剪影为主、以特征点为主各解一次。
  - 两次相机接近、残差都小 → 形和参考一致；
  - 剪影为主时特征点残差大到几倍 σ，特征点为主时 IoU 明显下降 → **模型的形和参考不一致**，相机在替形背锅。回 SKILL §1 / §4b 查造型（护臂：剪影为主时铰座残差 14 → 40 px；加大特征点权重后残差回到 7–17 px，IoU 却降到约 0.67；原因是铰座和叠板的造型错了，用户截图证实）。不要靠调 λ / σ 让某一个好看。
- **子集对照**：特征点按构件分组，去掉一组重解；去掉某组后其余自洽（视角稳定、与已知形一致），就是这组对应的结构写错了，常见是一个全局比例把不同件绑在一起——给它独立参数。机位先用自洽的组定。
- 标注点先叠回参考图核对一遍再用（裁剪偏移记错过一次）。

## 5. 族参数与支承体 [实测]

**族参数**：识别说"3 层叠板、节距相同、宽度递减"，就只放开 起点 v0、节距 p、首宽 w0、增量 dw、端角 θ0 这类量，不让每件各自乱动。参数个数 ≤ 参考上能独立读出的特征数的一半。

**支承体**（手臂、柱身、器物腹、壳体）：它决定所有贴附件的位置和整体剪影，必须从参考拟合，领域知识只当初值。
- 表示：轴线 c(v)（直线或少参数曲线）+ 截面尺寸 a(v)、b(v) + 截面形状（椭圆 / 超椭圆指数）+ 可选扭转 φ(v)。
- 尺寸曲线用少参数光滑函数：端值 + 一个峰（位置、峰值）+ 收分指数，或 3–5 个控制点的单调样条；不用两端线性插值（直管），也不把解剖 / 规制比例写死成最终值。
- 拟合数据：参考上外露支承段的剪影宽度 w(v)（按相机投影比较），以及支承上的已知形（环）；被件盖住的段用件的外缘间接约束。单视图只给一个方向的宽度，另一方向用扁率先验；有侧视图就用两视剪影（§2b）。
- **什么时候不用支承体拟合**：直线规整的刚性件（家具腿、方杆、箱体）直接量两端尺寸和撇角就够；`profilefit` 是给有粗细节奏的曲面支承（肢体、瓶腹、柱身收分、壳体）用的。
- 代码：`scripts/profilefit.py`（`bump` 两端 + 鼓包 5 参数、`Body` 超椭圆截面、`widths` 透视下逐点投影求剪影宽、`fit` 单视图 + 扁率先验 / 双视图）。合成自测：双视图两向尺寸曲线误差 < 1%；同一组数据用直管模型（`linear=True`）残差大 50 倍——直管 / 写死先验的代价是可以量出来的 [自检]。
- 护臂教训：把前臂写成"肘下 28% 处肌腹最粗"的固定先验后，拟合器内部 IoU 从 0.67 降到 0.59——推测是支承变粗把贴附件一起推到参考剪影外（同一轮还改了铰座，没有单独隔离；一轮只改一个量才能归因）。

## 6. 什么时候停 [实测]

- 粗模阶段：位置比例看着对、面型对（IoU ≈ 0.8）即停，精力转去分件和造型。
- 细模阶段：形状由识别与构造决定，只重拟相机；IoU 下降而结构更像时，先重拟相机再判断。
- 精度目标 = 参考自身噪声底（对称物体左右差、标点误差）。到了就停。
