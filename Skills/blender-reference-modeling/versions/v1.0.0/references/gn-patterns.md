# 构件库、修改器与几何节点套路

## 构件库 + 点实例化 [已验证]

- 每类构件做 N 个变体（带种子的小差异），放进一个排除渲染的 kit 集合；集合内对象顺序 = 实例索引。
- 排布算成记录 `(位置, 旋转, 缩放, 变体号)`，写成点云的属性，几何节点 Instance on Points 从 kit 集合按索引取件。
- 结构排布（行、列、分组）严格对称；随机只加在单件（小角度、小偏移、变体号），并用固定种子。

## 活修改器 [已验证]

| 需求 | 做法 |
|---|---|
| 棱线（曲面 / 建筑石木件） | Bevel（Angle 限制，Harden Normals）+ Weighted Normal（Keep Sharp），面设 smooth |
| 棱线（折面硬表面：护甲板、机壳） | Bevel（Angle 限制，2 段）+ 平着色；平面保持平，倒角只放转折棱（`polys_bpy.build_from` 的默认） |
| 特定棱做异形倒角（如内凹海棠角） | 写边属性 `bevel_weight_edge`，Bevel 用 Weight 限制、profile < 0.5 = 内凹；其后再叠常规倒角 |
| 左右 / 前后对称 | Mirror，镜像对象用场景原点的空物体 |
| 旋转体（瓶、柱础） | 剖面曲线 + Screw |
| 板厚 | Solidify |

倒角宽度必须小于相邻段距、最窄面宽、台阶高的一半，否则夹出退化面或自交；条件和定位方法见 `geometry-math.md` §5。

## 几何节点写属性、材质读属性 [已验证]

成因 → 属性 → 材质（Attribute 节点，Geometry 类型）：

| 属性 | 成因 | 节点思路 |
|---|---|---|
| `streak` 雨痕 | 雨水从上部挑檐 / 箍下沿往下流 | 横密竖疏的拉伸噪波，阈值后放大，再乘"越高越强" |
| `damp` 返潮 | 地面潮气上升 | `1 - z / H`，边缘叠噪波成不齐的潮线 |
| `wear` 棱损 | 磕碰在棱上 | `1 - max(|nx|,|ny|,|nz|)`：平面 0、倒角圆弧上大，再乘噪波让它断续 |
| `top` 积灰 | 灰落在朝上面 | `max(nz,0)^4` |
| `chip` 崩口 | 棱上缺块 | 噪波阈值 × 棱遮罩；同时沿法线向内位移 |

## 散布：用射线判成因，不用密度场 [已验证]

例：青苔只长在"朝上、低处、身后有立面挡着（存水背阴）"的地方。

1. 实化来源几何 → 朝上 × 低于阈值高度的面上均匀撒候选点。
2. 每点抬高几厘米，向四个水平方向各打一条短射线；碰到立面 = 背阴。
3. 背阴 × 成片噪波概率 × 随机数筛 → 删点 → 实例化苔团。

用"离立面近"的密度场会失败：场在顶点上算、按面插值，结果整面撒满。

## 几何位移的安全边界 [已验证]

- 位移沿法线，幅度远小于倒角宽度。
- 三棱交汇的角球（max|n| < ~0.66）上位移渐弱到 0：法线收敛，向内推会折叠。
- 别在基础网格上随机压低角点：Bevel 会夹出 ~1 mm² 碎面，任何毫米级位移都会自交。

## 性能预算 [已验证]

- **实例优先，晚实化**：几千片瓦、上百个斗拱件保持实例（Instance on Points）；只有后面要做"射线判成因 / 位移 / 布尔"的那部分才 Realize。
- 实例上读不到逐点属性；需要逐件差异时，在材质里用 Object Info → Random。
- 单次构建时间就是迭代速度。实测：青苔散布实化来源几何后，整座建筑的构建从 8 s 涨到 15–21 s。超过 30 s 就先查哪一步在实化或细分。
- 细分只给需要几何位移的件（石作 2 级）；纹理级的凹凸交给材质 Bump，不细分。
- 记录每版的求值三角面数（`gate_preflight` 只数原网格，会低估：实测原网格 5 万，求值后约 38 万）。
