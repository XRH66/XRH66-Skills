# 识别与逐级逼近：任何件都先有剪影体，再一层层找规律

本 skill 的长处是**规律**：制式构件、重复、对称、排布、装配关系、少参数曲线。短处是自由雕塑面。
扬长避短的办法不是"雕塑类不做"，而是**分级**：一律先做到剪影体，然后在里面挖出能规则化的子结构，挖到哪级算哪级。
L4 那种无规律的细节才交给材质、法线贴图或外部资产。

## 0. 先拆件：构件树 [已验证：修仙牌楼按 台基 / 柱 / 额枋 / 斗拱 / 屋面 拆，前缀与集合一一对应]

识别的第一步是拆，不是逐件提问：先知道由几个件构成、每个件出现几次、谁装在谁上，后面的八问、定级、构造顺序才有对象。

**层次**：整体 → 部件 → 件 → 基本单元。例：

```
牌楼
├─ 台基 TJ
├─ 柱 ZW ×4（镜像 + 平移）
├─ 额枋 EF
├─ 斗拱 DG ×n 朵（平移阵列）── 朵 → 斗 / 栱 / 昂（制式件）
└─ 屋面 SY
   ├─ 屋面壳、脊带（支承）
   ├─ 椽：飞椽 / 檐椽（沿檐线阵列，翼角扇开）
   ├─ 瓦：瓦 / 瓦当 / 滴水（面上排布）── 瓦当 → 花纹（浮雕，D4 对称）
   ├─ 当沟、盖脊（沿脊放样）
   └─ 吻兽、套兽（不规则 → 逐级）
```

**拆的依据**（按优先级，冲突时上面的优先）：

| 依据 | 怎么判 | 为什么 |
|---|---|---|
| 真实构造 | 这东西本来怎么造、怎么装（查资料，`research.md`） | 拆法和构造一致，装配关系、接口、后续细化才自然 |
| 材质 / 分缝 | 参考上颜色、质感、缝线的变化处 | 一件一材，材质分层才好做 |
| 重复 | 同形出现多次 → 一个件 + 排布规则 | 只做一次，靠实例展开 |
| 对称 | 只留基本单元 | 同上 |
| 规律性 | 内部无规律的部分单独成节点 | 它按级处理（L1 / L2），不拖累规则件 |

**每个节点记**：名字（前缀）、父节点、数量、排布规则（阵列 / 沿线 / 面上 / 对称群）、接口（坐在谁上、朝哪；原点放这里）、比例来源。

**support 还是 part**：support 只给"别的件贴附在它上面、它自己的外形要从剪影拟合"的体——手臂、柱身、屋面壳、器物腹。刚性的箱体、框架、腿是 part：柜体是 part，坐在柜体上的拉手是它下面的 mount，腿是柜体下面的 part。一件东西不一定有 support（家具、机械件常常没有）。

**根与父节点**：根 = 整件本身（role `assembly`），不是支承；支承是根下的 support 节点。父节点 = 这件**坐在 / 装在**哪个件上——它决定接口、⑧跟的是哪个面、构造时先做谁。同时贴着几样东西的件（皮带坐在皮板上、绕着臂、尾端掖进壳下），挂在承力或最先装的那个上，其余关系写进⑥装配。

**支承体也是节点**：件坐在什么上（手臂、柱身、屋面壳、器物腹），它的走势、粗细节奏、截面变化同样要识别并从参考拟合（`fitting.md` §5），不用直管 / 平板代替。外露的支承和覆盖在上面的件要分清（护臂：肋纹金属壳曾被认成外露衬袖）。

**件上的件也要拆**：板上的铰座、凸台、槽、铆钉是独立节点，各自有接口（坐在哪个面上）和造型（长宽比、朝向、窗槽形状），各切一张放大图。

**mount 还是 detail**：有自己的体积和接口、能单独拿下来看的（铰座、凸台、带扣、铆钉、徽章）是 mount，检查点 B 要逐件对照；长在父件表面、离开父件就不成形的（刻线、小卷纹、缝线、浅浮雕、和壳一体的凸筋）是 detail，按 §5 分诊后写去向 `route`：`separate` 独立网格 / `relief` 父件上的几何浮雕 / `normal` 法线 / `material` 材质 / `asset` 外部资产。拿不准时问"做错了用户会不会单独指出它"——会就是 mount。

**和八问来回**：拆完答八问时，常会发现新的重复或对称（例：斗拱一朵里的斗是同一件的几种尺寸），那就回来改树。树定下来才进定级。

## 1. 识别清单：树上每个节点都要答这八问 [实测]

| 问 | 要写出来的东西 | 例（瓦当 / 吻兽） |
|---|---|---|
| ① 它是什么、在哪 | 类别、在参考上的位置和比例来源、接口（坐在谁上、朝哪） | 瓦当：垄头，面朝檐外 / 吻兽：正脊两端，骑脊 |
| ② 对称 | 对称群：镜像、n 次旋转、平移（带状 / 阵列）、无 | 瓦当 D4 / 兽面左右镜像 |
| ③ 重复 | 同一件出现几次、哪些参数在变（尺寸渐变、变体） | 瓦当每垄一个 / 鳞片沿身由大到小 |
| ④ 轮廓 | 外轮廓、截面能否用少参数曲线写出（极坐标、超椭圆、κ(s) 分段、螺线、样条点数） | 花瓣 r(θ) / 卷尾对数螺线 |
| ⑤ 高度结构 | 台地 + 倒角、距离场拱起、自由起伏；有没有倒扣 | 瓦当 6 层台地 / 吻兽身体自由起伏 |
| ⑥ 装配关系 | 支承、贴合、搭接、净距、斜接、让位 | 瓦当挂筒瓦头 / 吻兽骑在脊上、压当沟 |
| ⑦ 面型 | 曲面 / 硬表面 / 混合。判据看明暗：连续渐变无棱线 = 曲面；成块、块间有亮棱或暗缝 = 硬表面 | 皮质衬袖 = 曲面 / 科幻护臂叠板 = 硬表面（外侧 3–4 个平面，转折处亮棱） |
| ⑧ 跟形与两向截面 | 跟不跟支承形及理由；沿主轴、绕主轴两刀截面各是曲线还是折线、几段 | 鳞片薄小 → 跟臂形 / 叠板刚性 → 自有折线截面，只用臂定位 |

②–⑤ 决定这件能走到哪一级（下表）；⑥ 决定装配时要检查什么（净距、干涉）；⑦⑧ 决定截面怎么造——判错了，后面拟合得再准也是另一种东西。
结果写进 `gate/ident.json`（`python scripts/gate.py init 项目目录` 出模板），每个叶节点附参考局部放大图。

## 1b. 开工前自检：核自己写的东西 [实测：科幻护臂]

| 核什么 | 怎么核 | 科幻护臂那次能抓到什么 |
|---|---|---|
| 拆到底了吗 | 这件上还有分缝、棱线、材质变化？有就继续拆 | 叠板 = 顶板 + 桡侧铰座方盒 + 前唇，只拆到"一块叠板" |
| 面型 | 放大这件，描述明暗：渐变还是成块？亮棱在哪 | 外侧 3–4 条亮棱 → 硬表面，不是弧带 |
| 跟形 | 刚性还是柔性？厚还是薄？ | 叠板刚性、厚 → 不跟臂形 |
| 两向截面 | 沿轴一刀、绕轴一刀各画出来 | 绕轴那刀没设计，被支承曲面"自动"决定了 |
| 惯性 | 这件的做法从哪个旧案例搬来？那里成立的理由这里还成立吗？ | "沿支承等参线放样"来自鳞片案例；鳞片薄、跟形，叠板不是 |
| 件上的件 | 板上的安装件拆出来了吗？长宽比、朝向、平坐还是嵌入？ | 铰座被当成"板的一段"，做成方盒切断叠板（检查点 B 前才由用户截图发现） |
| 支承 | 支承体的走势、粗细从哪来？外露的是支承还是覆盖件？ | 衬袖用线性直管；肋纹金属壳被认成外露衬袖 |

之后的粗模对比与检查点 A 按 SKILL §1b；记录写进 `gate/selfcheck.json`，每项写结论（不是勾选）。改了树就重跑 `gate.py ident`。

## 1c. 闸门字段表（`gate/ident.json`）

**顶层**

| 字段 | 写什么 | 闸门查 |
|---|---|---|
| `object`、`refs` | 物体名；参考图路径 | 非空、文件存在 |
| `classification` | `{主体, 插图, 标注, 干扰物, 存疑}` 各列哪些东西 / 区域，没有写 `[]` | 主体非空，没有模板占位 |
| `views` | 每个视图 `{id, ref, region, facing, use, note}`；`use` ∈ primary / aux / ignore | 至少一个 primary；ref 在 refs 里 |
| `ambiguities` | 检查点 A 要用户定的歧义，没有写 `["无"]` | 非空 |

**每个节点**

| 字段 | 谁要填 | 写什么 / 闸门查 |
|---|---|---|
| `id`、`name`、`parent` | 全部 | 根 id = `root`、parent = null；id 唯一；父链不成环 |
| `role` | 全部 | 根 = `assembly`；其余 ∈ support / part / mount / detail；mount 不能挂根 |
| `count` | 全部 | 正整数 |
| `level` | 全部 | 初定级 L0–L4 / skip；skip 要写 `skip_why` |
| `evidence` | 叶节点 | 局部放大图，文件存在，不能是参考原图 |
| `route` | detail、L4 | separate / relief / normal / material / asset |
| `profile_source`、`deliver` | support | `{method: silhouette_fit / known_shape / measured, views: [视图 id]}`；deliver 为布尔 |
| 八问：`interface` `symmetry` `repeat` `outline` `height` `assembly` | 出独立几何的 L0–L3 节点（route 为 normal / material / asset 的 detail 不用） | 不能留模板原文 |
| `surface`（+ `surface_note`） | 同上 | curved / hard / mixed；mixed 写哪部分硬、哪一向折线 |
| `conform`、`conform_reason`、`conform_why` | 同上 | 跟不跟所坐的面；reason ∈ thin / soft / small / rigid；跟形不能是 rigid，硬表面跟形只能 thin / soft |
| `section_along`、`section_around` | 同上 | `{type: curve / polyline, segments: 正整数}`；硬表面两向都是 curve 拦 |
| `inherited` | 同上 | 做法沿用自哪个旧案例、理由是否成立；无写 none |

`selfcheck.json` 每个核查项写一句结论；对这个节点不适用的项写"不适用：理由"（如拉环的"支承"），单字符、"ok"、"—"不算。

闸门只查字段在不在、自不自洽，"判得对不对"靠粗模对比、冷读和用户过目。

## 2. 逐级逼近 L0–L4 [L0–L1 已验证于构件；雕塑类 待验证]

| 级 | 做什么 | 验收 |
|---|---|---|
| L0 占位 | 包围盒 + 接口点 + 朝向 | 尺寸、位置、和相邻件不穿 |
| L1 剪影体 | 外轮廓拟合成体（下面 §3） | 参考机位剪影 IoU（`silhouette_iou.py`）+ 轮廓残差，达到参考噪声底 |
| L2 分块 | 大体块与主转折（头 / 身 / 尾 / 卷；座 / 身 / 顶） | 各块剪影、主转折线回代 |
| L3 规律细节 | §4 清单里能规则化的全部规则化 | 同机位对比；规律参数可调、有种子 |
| L4 无规律细节 | 停。交给材质 / 法线 / 外部资产，或留作手工 | — |

识别表里给每件写**目标级**。规则构件（瓦、椽、斗拱）通常直接 L3；纹饰多到 L3；吻兽、兽面、龙至少 L1、L2，L3 尽量（鳞、鬃、卷、刻线）。
一轮只升一级，和"大形不过不进中形"同理。

## 3. 剪影体：从轮廓做体（数形结合的体版本）[待验证；代码 `bodies.silhouette_body / width_from_mask` 自检通过]

- **两视或三视剪影**：沿主轴切片，每片宽度取正视剪影、深度取侧视剪影，截面用超椭圆（指数 = 方 / 圆，可拟合），切片放样成体。
  天然是同拓扑环 → 四边面，不用布尔求交（布尔视壳会出三角面和碎面）。
- **只有一视剪影**：深度是歧义 → 出方案族（等厚 / 中鼓 / 前后收，或从同类实物的比例查证），同视角并排给人挑。同 `math-form.md` 3.7。
- **轮廓本身**：少控制点样条或 κ(s) 分段拟合，点数尽量少；残差到参考噪声底就停（点多 = 线抖、没势）。
- **主轴是曲线时**（龙身、卷尾）：先拟合脊线（螺线 / κ(s)），切片沿脊线的标架排，截面宽深沿弧长取。

## 4. 在不规则物里挖规律：L3 清单 [待验证，前几项在构件上已用过]

| 子结构 | 数学对象 / 原语 | 例 |
|---|---|---|
| 卷、云头、卷鬃 | 对数螺线、阿基米德螺线（2–3 参数） | 吻兽卷尾、云纹 |
| 鳞、甲片、瓦、砖、板 | 面上排布：起点沿边界等距，按方向场推进，碰停止场就停；尺寸渐变 + 成组随机 | 龙鳞、瓦垄、甲板 |
| 鳍、鬃、齿、椽、栏杆 | 沿曲线渐变阵列，同一截面按参数缩放 | 背鳍、椽、望柱 |
| 刻线、眉骨、线脚 | 表面上的偏移曲线 → 浅槽 / 凸棱放样 | 兽面刻线、额枋线脚 |
| 左右 / 旋转对称 | 只做基本单元，按对称群展开 | 兽面、瓦当、团花 |
| 台地浮雕 | 平面轮廓 × 高度剖面（§5） | 瓦当、回纹、莲瓣 |

## 5. 纹饰与浮雕：分诊 + 原语

**分诊**（决定能到哪级，不是能不能做）：

| 判据 | 好做（L3） | 要拟合（L2–L3） | 到 L1–L2 为止 |
|---|---|---|---|
| 对称 | 旋转 / 镜像 / 平移 | 局部对称 | 无 |
| 平面轮廓 | 少参数曲线 | 少量控制点样条、傅里叶级数 | 大量自由曲线 |
| 高度 | 台地 + 倒角 | 距离场拱起 | 自由雕刻面 |
| 体积 | 2.5D 无倒扣 | 简单倒扣（分件） | 全 3D 有机 |

例：回纹（网格折线 + 平移）最好做；莲瓣、瓦当花、团花能做；云纹、卷草要拟合；兽面、龙按 §2 逐级。

**浮雕原语** [实测：修仙牌楼瓦当 `kit_tiles.make_wadang`]：
- 平面轮廓：一条参数曲线经对称群展开。瓦当花瓣 r(θ) = a(1 + b·cos(nθ + φ))，n = 瓣数、a = 大小、b = 瓣深、φ = 相位。
- 高度剖面：径向分层台地（瓦当：背面 → 侧壁 → 外圈凸棱 → 平地 → 花瓣凸台 → 当心圆台），每层 = 一条轮廓 + 一个高度。
- 构造：每层轮廓在**同一组角度（或弧长）**上采样 → 同拓扑环 → 相邻环连四边面；只有中心和背面用平面 n-gon 收口；不用布尔；最后小倒角（小件 3–5 mm）。
- 不要走"照片灰度 → 高度"：明暗来自光照和固有色，不是深度。
- 不是星形 / 回转对称的任意轮廓（涡卷徽饰、十字、字形）：`bodies.relief_slab`——每层一条闭合轮廓 + 高 + 斜边宽，距离场叠成台地，输出闭合高度场实体 [自检]。快、通用，但轮廓有网格锯齿（分辨率 ≤ 斜边宽 / 3）；轮廓要锐利的件仍走上面的同拓扑环做法，或只作法线来源（route = normal）。

**从参考拟合纹样** [待验证]：
1. 从参考图描纹样边缘（`ref_trace.py`）；
2. 认对称阶数 n；
3. 用只含 n 的倍数次谐波的傅里叶级数拟合 r(θ)（上面那条是只留一项的特例），项数加到残差到噪声底为止；
4. 带状纹换成沿路径的周期函数，做法相同。

瓦当那次的教训：识别、构造做对了，但 a / b / 圆台占比是目测定的、直接写在 kit 里，也没核对参考里的纹样本身。
纹饰也要走"认线 → 拟合 → 回代"，参数进 spec。
