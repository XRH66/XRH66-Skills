# 案例：科幻叠板护臂（第三案例，照参考，硬表面）

项目：作者本机 `default-workspace/case-gauntlet/`（不随 skill 发布）（参考 `ref/ref01.png`；手 / 手套不做，只做护臂）。2026-11-20 → 11-21，停在检查点 B 之前。
这个案例检验的是**照片参考 + 硬表面 + 叠层装配**。原语层的通用度已由鳞甲护臂验过，这里检验的是方法层。它暴露的问题几乎都出在方法和顺序上，不在算法上。

## 构件树（最终版）

```
护臂
├─ 衬袖（支承：肋纹管，外露在肘端上沿与腕部间隙）
├─ 肘端护片：L 形包边框 + 肋纹壳（6 片横向叠片）+ 下沿横带（带空窗铰座，无销）
├─ 叠板 ×3（连续折面板；尺侧凸起小面板 + 槽；桡侧铰座折面上一个扁宽铰座 + 长槽 + 铰销；铆钉 ×2）
└─ 腕甲：下层（前缘尖唇、向手外翻）+ 上层护片
```

## 读数

- 剪影 IoU（同机位）：v2 初版 0.703 → 修长度 / 厚度 0.773 → 铰座挪位（相机未重拟）0.734 → 重拟相机 0.779 → 加肋纹壳与腕甲外翻 0.796（旧相机）；之后加大特征点权重重拟，拟合器内部剪影 IoU（numpy，未渲染）0.666 → 铰座重做 + 固定肌腹先验后 0.594。
- 审计（最后一版）：求值后 0 自交 / 0 退化 / 0 非流形；14 件两两 0 对相交；四边面 99.8%。
- 修过的构造坑：倒角在加密站窄条上自交、销台肩小于 2 倍倒角出退化面、尖唇折点夹紧挤出窄条、外翻转折处缺站。
