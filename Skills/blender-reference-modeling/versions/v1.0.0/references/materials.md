# 写实材质：按成因分层（Cycles 程序化）

现成实现：`scripts/layered_material.py`（纯 bpy，不依赖插件或第三方节点）。
- `build(kind, name, **覆盖参数)`；kind = tile / ridge / bed / wood / lacquer / frame / plaster / stone / stone_dark / ground / moss。
- 无头色板自检：`blender --background --factory-startup --python layered_material.py -- --swatch out.png`。
- 参数单位：尺度 1/m（Object 坐标），颜色是线性 RGB。新项目复制后把参数挪进 spec，再按参考调色。

## 通用叠层顺序 [已验证]

1. **底色 + 逐件色差**：Object Info → Random，对几何节点实例逐件生效。用它做冷暖偏移和明度 ±x%，同时平移纹理坐标，让每件纹理不同。
2. **大尺度斑驳**（≥ 30 cm）：低频噪波调明度。
3. **结构纹理**：取决于材料本身（年轮、晶粒、层理、龟裂）。
4. **风化**：朝上（法线 z）、立面雨痕（z 向拉伸噪波 × (1 - |nz|)）、地脚泥渍（世界 z）。
5. **缝脏**：AO（外向）低处压暗。
6. **棱损**：AO `inside=True` 取凸棱度。**必须取反**：平面上向体内的射线穿到远端无遮挡 = 1，棱角处 = 低。
7. **粗糙度与凹凸同源**：用驱动颜色的同一批噪波去驱动粗糙度和 Bump；两级 Bump 串联（宏观起伏 → 微观颗粒）。

坐标用 Object 空间（米）；尺度参数都以 1/m 为单位写进 spec。

## 尺度带检查 [已验证：建筑；小物体按比例换算 待验证]

做完一个材质，按特写机位看三个尺度带是否都有内容。下表的绝对值是建筑尺度（构件米级）；小物体（护甲、器物、机械件）按构件尺寸等比换算——大 ≈ 一个构件的尺度，中 ≈ 构件的 1/20–1/2，小 = 常规机位下仍有 1–2 像素以上的最细纹理。

| 尺度带 | 建筑尺度 | 典型内容 |
|---|---|---|
| 大 | ≥ 30 cm | 色带、褪色、返潮；小物体：分件色差、整片磨旧 |
| 中 | 2–15 cm | 斑驳、蚀坑、锈渍、裂隙、地衣；小物体：棱边磨亮带、划痕簇、油污 |
| 小 | ≤ 1 cm | 晶粒、孔隙、纤维；小物体：拉丝、细划痕、微凹坑 |

"像水泥"＝中间带空白；"像塑料"＝粗糙度单一、凹凸太平。亚毫米细节在常规机位下看不见，不算数。

## 配方要点

**岩石（青石）** [已验证]：扭曲 fbm 驱动 4 段色带（逐块沿色带平移）+ 10 cm 斑驳 + 不规则水平层理（z 向压密的噪波）+ ridged 噪波方解石脉（局部遮罩）+ Voronoi 晶粒（逐粒明暗 / 粗糙度）+ 极稀白斑 + 风化蚀坑（高细节噪波阈值）+ 竖向锈渍 + 局部发丝裂隙 + 雨痕 + 地衣圆斑 + 两级 Bump + 凹处压暗。
- 别用：Wave 条带做层理（斑马纹）、Voronoi 圆坑（像混凝土气孔）、规则平行剁斧道（像灯芯绒）。

**老木（不施彩）** [已验证]：Wave RINGS 年轮（轴 = 件的长向）+ 顺纹拉伸噪波纤维（长向尺度 1、横向 ~45）+ 拉长 Voronoi 边线做干裂（大噪波遮罩，只在局部）+ 朝上泛银灰 + 棱角磨浅。年轮对比要低、尺度要细，否则成斑马。

**朱漆** [已验证]：褪色斑 + 竖向雨痕 + Voronoi 边线龟裂 + 剥落露灰白地仗（噪波 + 凸棱偏置，阈值很窄）；剥落处去清漆层、粗糙度高。

**灰浆墙** [已验证]：两级刷浆斑驳 + 起皮露底灰 + 砂粒 Bump + 发丝裂（先用噪波扭曲坐标再进 Voronoi，否则是规则多边形网）+ 几何节点属性（雨痕 / 返潮，潮处降粗糙度）。

**陶瓦 / 青砖** [已验证]：逐片冷暖 + 明度色差、窑变斑、细孔 Bump、朝上地衣斑、棱角磨浅、缝脏。

**金属 / 涂装硬表面（护甲、机壳、器械）** [待验证：护臂案例只做到几何，材质没做]：底色金属度 1、按件分区的粗糙度（0.3–0.6）+ 逐件色差 + 拉丝 / 划痕沿件的主方向拉伸 + 凸棱度驱动的棱边磨亮（降粗糙度、提明度）+ 缝脏（AO）压暗 + 中尺度油污 / 指纹斑（粗糙度变化为主）+ 微凹坑 Bump；涂装件在漆层下叠金属层，用棱损遮罩剥出。金属反照率、粗糙度范围先查测量数据（`research.md`），不凭感觉定。

**夯土地面** [待验证]：两色大斑 + Voronoi 碎石（局部成片）+ 细砂 + 离建筑越近越湿暗。目前偏素，碎石在常规距离下不显。

## 评估条件 [已验证]

- 固定一盏侧向日光（临时加，渲完删），看凹凸。
- 关掉用户的调色合成（临时，渲完恢复），看真实明度；最后再出一张带用户合成的给用户看。
- 只用天光、平光时凹凸几乎不可见，不要据此判断材质。

## 第三方噪波节点 [已验证可用，不进交付]

Noise Nodes 插件里的 Crackle（龟裂网）、Streaks（竖向流痕）、Scratches（细划痕）、Dent（凹坑斑）、Cranal（脉络网）可以直接当风化层的原语，交互调材质时省事。但它们是插件注册的自定义节点，没装插件的机器上会断。交付的 .blend 和构建脚本里不用它们；看中某个效果，就用内置的 Noise / Voronoi / Wave 复现。
