# 案例：鳞甲护臂（第二案例，非建筑）

目的：检验几何原语层的通用度——换一个和建筑无关的对象，原语要改什么。项目：作者本机 `default-workspace/case-bracer/`（不随 skill 发布）（`README.md` 有构件树、六问、定级）。
无照片参考，比例按常见形制定在 `spec.py`；本案例验收几何，不做成因材质。

## 构件 → 原语

| 构件 | 规则 | 原语 |
|---|---|---|
| 衬壳 | 截椭圆锥 + 微鼓，等厚 | `support.Surface` + `shell_polys`（全四边面，闭合） |
| 鳞片 ×133 | 沿轴成排（排距 = 片长 × (1 − 压叠)，随周长变）、排内等分、隔排错半片、排端半片；三种片尖 + 左右半片；成组微倾 + 抖动 | `arrange.march`（步长函数）→ `fit` 收口 → `starts_along`（3D 周线）；`Surface.normal / dv` 定标架；`instancing.stack_drop` 定倾角；`jitter`；`instancer_bpy` |
| 鳞片 kit | 外轮廓（上平、侧直、片尖超椭圆）× 同拓扑内收环（台地拱起）× 横弯 | 浮雕原语做法（同牌楼瓦当） |
| 包边 | 开口四边一圈 C 形截面（边带 + 卷边 + 内翻边），四角斜接 | `sweep` 3D 标架 + 闭合环 |
| 系带 ×2 | 横跨开口贴面绕行 | `sweep.stations3` |

## 暴露的缺口（都补进 skill，补完牌楼回归仍逐字节一致）

| 缺口 | 现象 | 补法 |
|---|---|---|
| 支承只有竖直射线 z(x, y) | 柱 / 锥不是高度场 | `Surface(f(u, v))`：点、法向、标架（含倾角）、等参线、偏移、壳 |
| 放样只有 2.5D | 截面横向必须水平、z 绝对 | 站带 n 即 3D 模式：截面 (u, v) → p + lat·u + n·v；`closed` 闭合环 |
| 步长固定 | 片随处变大，排距跟着变 | `march` 的 step 可为函数 |
| 停在边界前留空 | 腕端空出近一个排距 | `arrange.fit` 等比拉开收口 |
| 3D 斜接法向 | 两段端点各按弦切向正交化，平均后 lat 不垂直 n | 斜接站 lat 再正交一次（保留 1/cos 长度） |

## 两条规律（都是牌楼教训的再现 → 写进 pitfalls）
1. **叠层净距要计入随机量与曲率失配**：只留名义净距 0.4 mm 时相邻排互穿 72 对；计入随机量（约 0.5–1.1 mm）和曲率失配（0.3–0.45 mm）后 0 对。与牌楼"两层椽"同一规律。
2. **斜接剔站距离 ≥ 截面在折角内侧的伸出量**：按截面宽 × 0.45 / 0.6 取时四角自交 57 / 58 处，取边带宽 + 0.5 后 0。

## 读数
- 鳞片 133（16 排，9 / 10 交替），倾角 10.4°（肘）→ 14.9°（腕：片小、片距短）。
- 审计：`eval_audit` pass（0 自交 / 0 边界 / 0 非流形 / 法线朝外）；`audit_instances` pass（133 片 0 对）；成件四边面 100%，包边 Bevel 后四角有 16 个 n-gon。
- 证据：`build/bracer_overview.png`、`build/shots/`、`MANIFEST.md`。

## 还没验证的
- 片的倾角偏大（10–15°）：随机量占净距的一半以上；想要更伏贴，就收小随机或让 kit 按排换弯曲半径（现在一个 kit 横弯固定 R46）。
- 没有照片参考，没走"认线 → 拟合 → 回代"那一段；通用度只验证了构造与排布层。
